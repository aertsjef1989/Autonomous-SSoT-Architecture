Best on desktop (>= 900px): Signal Studio is a 16:9 canvas slide editor designed for desktop viewports. Mobile view provides read/preview access.
SIGNAL STUDIO
TEMPLATES
A template drops its objects onto the current slide. Everything it drops is editable.
PROPERTIES
Nothing selected. Click an object on the canvas.
FIND AND REPLACE
Searches text, tables, chart labels, callouts, pills and buttons, on every slide.
ASSETS
Uploaded once, stored in the project file, reusable on any slide. Click to place, drag to move like anything else.
BRAND MARK
Placed on every slide automatically, always on top, never dragged by accident. The dashed guide shows clear space and is never exported.
ALIGN
DECK TYPOGRAPHY
Tag a text object with a style, then change the style once and every tagged object on every slide follows.
